# jakeabailey.github.io

The root of the GitHub Pages domain, kept in the Widgetdown repo at `Root Site/`.
It's here for `.well-known/apple-app-site-association`, which lets shared
countdown links (`https://jakeabailey.github.io/widgetdownsite/add/#…`) open
straight in Widgetdown (Universal Links). Apple only reads that file at the
domain root. `.nojekyll` stops GitHub Pages hiding the `.well-known` folder.
The home page redirects to the site at `/widgetdownsite/`.
